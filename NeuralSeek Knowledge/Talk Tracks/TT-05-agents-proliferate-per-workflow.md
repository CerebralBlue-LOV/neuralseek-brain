# TT-5. "Agents proliferate per workflow, not per user"

## Punchline
"In 2030, a single knowledge worker will run many agents simultaneously, and those agents will spawn other agents. That compounds. Each agent runs many tasks, each task uses many tokens. Tasks and tokens grow significantly faster than agent count itself."

## Why this lands
Forces the listener to stop thinking "one user, one agent" and start thinking about scale.

## NeuralSeek tie-in
Hand-in-glove with our 4-layer token throttling (API → agent → swarm → platform). Lawrence's existing line about "the Uber AI bill blowing up" lands harder when you pair it with this point.

## Use
CFO / CTO budget conversations. The token-cost-control pitch.
