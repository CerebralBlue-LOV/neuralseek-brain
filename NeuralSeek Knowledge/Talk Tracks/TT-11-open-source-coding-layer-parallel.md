# TT-11. The "Open-Source Coding Layer" parallel

## Category
Where NeuralSeek sits in the AI marketplace

## Punchline
"Open-source agent code harnesses may not match the scale of Claude Code, Codex or Cursor, but they are being used at production scale today. OpenClaw alone processes ~10.8T tokens per month."

## Why this lands
Establishes that open-source agent harnesses already dominate one vertical (coding). The implicit question: who's the equivalent for regulated enterprise workflows?

## NeuralSeek tie-in
"OpenClaw is the agent harness for coding. NeuralSeek is the agent harness for regulated enterprise workflows. Same architectural pattern, completely different control requirements."

## Use
Conversations with technical buyers familiar with the OpenClaw/Claude Code ecosystem.
