# Code of Conduct

## Our standard

The NeuralSeek Central Brain is a public knowledge base maintained by
[NeuralSeek](https://neuralseek.ai). We expect everyone interacting
with this repository — through issues, pull requests, discussions, or
external citation — to act with professionalism and respect.

### Encouraged

- Specific, factual, sourced contributions and feedback
- Constructive technical and editorial critique
- Asking questions clearly, with enough context for someone to help

### Not tolerated

- Harassment, personal attacks, or discriminatory language
- Misrepresenting NeuralSeek, its customers, or its team
- Using this repository's content to mislead, defame, or deceive
- Spam, off-topic promotion, or solicitation

## Scope

This Code of Conduct applies to all repository surfaces — issues,
pull requests, discussions, commit messages, and any communication
that references this repository on external platforms.

## Enforcement

Concerns can be reported to
[lawrence@neuralseek.com](mailto:lawrence@neuralseek.com). All
reports will be reviewed promptly. Repository maintainers may
remove, edit, or reject comments, commits, code, issues, and other
contributions that violate this Code of Conduct, and may ban
contributors whose behavior they deem inappropriate, threatening,
offensive, or harmful.
